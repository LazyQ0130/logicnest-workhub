# 网络端点清单

## 产品必需

| 类别 | 地址来源 | 默认行为 |
| --- | --- | --- |
| 账号与授权 | `LOGICNEST_LICENSE_API_URL` | 开发为 `http://127.0.0.1:8787/api/v1`；生产必须显式配置 HTTPS |
| 模型供应商 | 用户配置的 provider base URL | 仅在用户配置并使用模型时访问 |
| MCP | 用户添加并启用的 MCP 配置 | 默认无远程市场；仅访问用户配置目标 |
| IM | 用户添加并启用的平台配置 | 默认不启用；托管邮件通道在首发关闭 |

## 明确关闭

上游遥测、广告、订阅/积分、更新检查、远程 Kits、技能市场和 MCP 市场不作为有效端点。兼容代码中的历史标识不会触发网络请求；品牌扫描会阻止已知上游域名重新进入活动源代码。

桌面通用 fetch 代理只接受 HTTP(S)，拒绝 URL 内凭据，并默认阻止非回环私网、链路本地和本地域名，避免被渲染进程用于访问内部服务。回环地址仅用于本地开发与本地组件通信。
