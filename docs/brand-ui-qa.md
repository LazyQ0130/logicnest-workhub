# 逻栖工枢品牌 UI 验收记录

日期：2026-08-04

## 桌面端

- 保留简约黑白界面、原侧栏结构及经典浅色、经典深色、跟随系统主题。
- 无会员登录后只出现激活界面，工作中枢和 OpenClaw 不初始化。
- 真实 DAY 卡激活后应用自动重启并进入完整工作中枢；主题、账号、授权和工作目录在后续 10 次启动/关闭循环中保持一致。
- 封停、撤销、过期、离线宽限结束和退出登录均退出核心主体；恢复、解绑或重新登录遵循后台授权状态。
- `MediaModelPicker` 保持移除，没有恢复停用的媒体生成入口。

## 运营中心

- 4175 生产容器登录页实际显示“逻栖工枢 · 运营中心”“运营中心登录”“登录运营中心”和“关键操作将记录审计日志”。
- 登录后实际检查运营概览、用户、套餐与卡密、设备、审计日志及退出登录页面。
- SUPER_ADMIN、OPERATOR、AUDITOR 的导航、按钮和直接路由权限均按角色生效。
- 匿名登录页不误报“登录已失效”；真实会话失效时提示一次，刷新后不重复。
- 当前容器内脚本与本地生产构建脚本 SHA-256 相同，生产启动脚本会再次验证标题和关键文案。

## Logo 保护

- 本轮未修改、重绘、裁剪、换色或重新生成甲方 Logo。
- 修改前基线与修改后最终 SHA-256 共比对 17 项，结果为 `17/17` 一致、`0` 项差异。
