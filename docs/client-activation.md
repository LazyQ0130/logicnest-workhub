# 客户端激活与使用

## 注册与登录

启动逻栖工枢后，在授权页输入手机号和密码。新用户可直接注册；密码至少 10 位并满足界面提示。登录成功但无有效会员时，客户端仍保持受限，不会启动 Agent 运行时。

## 激活

输入卡密并点击激活。后台默认使用“一卡一设备”模式：卡密绑定一个账号和一台设备，同一绑定重复提交会返回原授权结果，不重复延长。切换为“一卡多设备（单账号单在线）”后，同一账号可以在多台设备使用同一张卡密，但新设备登录会让旧设备会话失效。

## 离线使用

在线心跳会更新本机加密会话和 Ed25519 签名离线凭证。断网后最多可继续使用 72 小时，但不会超过会员到期时间。超过宽限、检测到时钟回拨、签名/设备不匹配、账号或设备被封停时，客户端进入受限页，联网验证后才能恢复。

## 换机与解绑

换机前由管理员在后台解绑旧设备；解绑会使旧设备会话与离线授权失效。单设备模式下，解绑后原账号可以在新设备重新使用原卡密；多设备模式下，原账号可以直接在新设备登录或提交原卡密。不要复制用户数据目录或授权缓存到其他计算机。

## 数据位置与隐私

Windows 本地数据位于 `%APPDATA%\逻栖工枢`。应用不启用上游遥测、广告和远程市场；模型供应商、用户启用的 IM/MCP 以及授权 API 仍可能产生网络请求，详见 `network-endpoints.md`。
