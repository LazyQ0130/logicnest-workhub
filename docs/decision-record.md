# 技术决策记录

## ADR-001：授权门禁早于 Agent 运行时

桌面主进程完成 SQLite 初始化后先初始化授权控制器。仅当在线会话有效或本机持有通过 Ed25519 校验、未超过 72 小时且未超过会员到期时间的离线凭证时，才启动 OpenClaw、IM、技能服务、代理和定时任务。授权丢失时停止上述能力并广播受限状态。

## ADR-002：服务端保存摘要，不保存可复用秘密

密码使用 Argon2id；卡密、refresh token、设备指纹和 IP 使用互相独立密钥的 HMAC/摘要。完整卡密仅在生成响应和当次 CSV 中出现。桌面 refresh token 通过 Electron `safeStorage` 加密后落盘。

## ADR-003：一码、一账号、一设备

MySQL 唯一约束、事务和行锁共同保证兑换幂等与并发安全。设备解绑、账号封停、设备封停会递增授权/令牌版本并撤销相关 refresh 会话。

## ADR-004：关闭上游运营外联

官方更新、遥测、广告、远程 Kits、技能市场和 MCP 市场默认关闭；上游服务地址不再作为有效网络目标。模型供应商、用户显式配置的 MCP/IM 与 LogicNest 授权 API 属于用户可理解的业务外联。

## ADR-005：技能默认拒绝

仅启用已经纳入本版本审计范围的本地文档与计划类技能。未知技能或远程安装请求失败关闭；运行时配置继续执行 OpenClaw 自身的权限和沙箱策略。
