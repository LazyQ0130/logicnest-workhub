# 本地技能审计

## 方法

审计以 `SKILLs/skills.config.json` 为准，检查技能说明、脚本入口、网络访问、命令执行、文件写入、凭据处理和依赖安装。运行时对未知技能采用默认拒绝，远程市场、下载和升级入口关闭。

## 首发白名单

| 技能 | 状态 | 理由与边界 |
| --- | --- | --- |
| docx | 启用 | 本地 Word 文档生成/处理；受工作目录与执行权限约束 |
| xlsx | 启用 | 本地表格生成/处理；不自动上传文件 |
| pptx | 启用 | 本地演示文稿生成/处理；不自动上传文件 |
| pdf | 启用 | 本地 PDF 读取/生成；渲染器仍按不可信输入处理 |
| create-plan | 启用 | 生成本地计划，无外部服务依赖 |
| local-tools | 启用 | 仅允许审计后的本地工具入口，仍需遵守权限提示 |
| skill-vetter | 启用 | 用于静态检查候选技能，不代表自动批准 |
| skill-creator | 启用 | 只创建本地技能草稿；启用前必须再次审计 |

网络搜索、远程下载、邮件、社交平台、媒体生成及其他未列出的技能在首发配置中禁用。用户自行添加的技能、MCP 或脚本不属于本报告保证范围，应按同一流程重新审计。

## 结论

首发配置满足最小启用面和默认拒绝。残余风险来自文档解析库漏洞、用户显式授权的命令执行，以及 OpenClaw/依赖更新后的行为变化；每次升级必须重新审计并记录版本差异。
