# 管理后台使用手册

1. 使用管理员账户登录。首次登录必须修改初始密码。
2. 仪表盘查看注册用户、有效会员、今日新增、在线设备和七日内到期数量。
3. 在“用户”中按 UID/手机号筛选，查看详情、封停/恢复、重置密码或解绑设备。
4. 在“套餐与卡密”维护 1 天、30 天、365 天等套餐，并在“卡密授权模式”中选择“一卡一设备（解绑可换机）”或“一卡多设备（单账号单在线）”。有关联记录的套餐应停用，不应删除。
5. 批量生成卡密时选择套餐、数量（每批最多 1000）和可选失效时间。完整卡密仅在本次结果中可见，应立即下载 CSV 并安全交付。
6. 已生成卡密可按批次、套餐、状态和末四位查询；吊销操作需要填写原因并进入审计日志。
7. 在“设备”中查看在线状态、封停、解绑或强制会话失效。
8. 在“审计日志”中按管理员、动作、对象和时间检索敏感操作。

角色权限：`SUPER_ADMIN` 可执行全部操作；`OPERATOR` 可运营用户、套餐、卡密和设备；`AUDITOR` 只读。界面隐藏不代表安全边界，最终权限由 API 校验。

不要在工单、聊天或截图中传播完整卡密、密码、cookie、token、原始设备标识或完整手机号。排障使用响应中的 `requestId` 对照服务端日志。
